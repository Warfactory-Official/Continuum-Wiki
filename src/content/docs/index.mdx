NTM - Continuum ports HBM's Nuclear Tech Mod 1.7.10 to six targets from one source tree. Almost everything a pack
maker wants to change is data: machine recipes, fluid properties, hazard values, reactor fuels and loot pools are all
datapack files, and every one of them is reachable from KubeJS too. Addon mods get the same APIs HBM uses itself.

The wiki has one section for each way of changing the mod. Each section has its own sidebar with everything you need
for it, including the machine recipe, data map and fluid pages all three share. Switch sections at the top of the
sidebar.

<CardGrid>
	<Card title="Datapacks" icon="document">
		Add or remove recipes for any of HBM's machines, change fluid traits, hazard levels, reactor fuels and more,
		with plain JSON. No other mod needed, works on every loader.
	</Card>
	<Card title="KubeJS" icon="seti:javascript">
		Every machine table is a KubeJS recipe type. The `HBM` global reads and writes radiation, and `HBMEvents`
		reports nukes, missiles and finished machine recipes.
	</Card>
	<Card title="Addon mods" icon="puzzle">
		Register blocks, fluids, materials and bullets, substitute HBM blocks with your own subclass, and hook into
		HBM's environment rules. No mixins needed.
	</Card>
	<Card title="Six targets" icon="setting">
		26.1 NeoForge and Fabric, 1.21.1 NeoForge and Fabric, 1.20.1 Forge and Fabric. The same files and scripts work

	</Card>
