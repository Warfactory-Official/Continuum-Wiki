# {{modName}}

An addon mod for [NTM - Continuum](https://github.com/Warfactory-Official/NTM-Continuum), generated by the
[Continuum Wiki](https://warfactory-official.github.io/Continuum-Wiki/addons/overview/) template generator.

It builds for these nodes (Minecraft version and loader): {{nodeList}}. Golem Core, NTM - Continuum and GemRender come
from CurseForge through [CurseMaven](https://www.cursemaven.com/), so no other checkout is needed.

## Building

You need a JDK to start Gradle (any of 17, 21 or 25). Gradle downloads the Java each node needs (26.1 on 25, 1.21.1 on
21, 1.20.1 on 17).

```bash
./gradlew :{{activeNode}}:dejsonVerify   # every declared texture exists
./gradlew :{{activeNode}}:runClient      # start a dev client
./gradlew chiseledBuild                  # build every node
```

Jars land in `versions/<node>/build/libs/`; the copies without GameTests, for uploading, in `versions/<node>/build/release/`.

The source tree is written once, against the newest node's API. Stonecutter rewrites `src/` in place for the active
node (`{{activeNode}}`), so only one node compiles at a time. `chiseledBuild` switches between them; run
`./gradlew "Reset active project"` before you commit.

Put a version difference in Golem Core, not behind a `//? if` guard here. Loader guards (`//? if neoforge`) belong only
in the `platform` packages.

## Updating Golem Core and NTM - Continuum

Each `versions/<node>/gradle.properties` names CurseForge file ids:

- `deps.golemcore`: a file of https://www.curseforge.com/minecraft/mc-mods/golem-core/files/all
- `deps.hbm`: a file of https://www.curseforge.com/minecraft/mc-mods/ntm-continuum/files/all
- `deps.gemrender`: a file of https://www.curseforge.com/minecraft/mc-mods/gemrender/files/all

The file id is the number at the end of the file's page URL. Pick the file for that node's Minecraft version and loader.
When you move to a newer Golem Core, also raise `deps.golemcore_floor` and `deps.hbm_floor` in `gradle.properties` and
copy the matching `gradle/mod/*.gradle.kts` scripts from that Golem Core release into `gradle/golem/`.
