# {{packName}}

A datapack for [NTM - Continuum](https://github.com/Warfactory-Official/NTM-Continuum), generated by the
[Continuum Wiki](https://warfactory-official.github.io/Continuum-Wiki/datapacks/overview/) template generator.

It works on Minecraft {{versionList}}.

## Installing

Put the zip as it is in a world's `datapacks` folder (`saves/<world>/datapacks`), then run `/reload` or reopen the
world. To edit the pack, unzip it into a folder there instead and remove the zip. `/datapack list` should show
`file/{{folderName}}.zip` (or `file/<folder name>`) as enabled.

## What is in it

- `pack.mcmeta`: the pack format for the versions above.
{{#example}}
- `data/{{namespace}}/{{recipe}}/press/example_diamond.json`: a Burner Press recipe that presses a gold block into a
  diamond with a flat stamp. Delete it once you have your own recipes.
{{/example}}
- `data/{{namespace}}/recipe_removals/removals.json`: recipes to remove, by id (for example `"hbm:press/ball_resin"`).
{{#overlay}}

Minecraft 1.21 renamed several vanilla data folders from plural to singular (`recipes/` became `recipe/`, `tags/items/`
became `tags/item/`, and so on). This pack keeps the 1.20.1 spelling in `data/` and the newer spelling in
`{{overlayDir}}/data/`, an overlay that 1.21.1 and newer load instead. Put a file in both places, or only in the folder
for the versions it is for. HBM's own folders (`recipe_removals`, `value_maps`, `fluid_property`,
`fluid_property_patch`, `fallout_transform`, `item_pool`) have the same name everywhere, so they stay in `data/`.
{{/overlay}}
